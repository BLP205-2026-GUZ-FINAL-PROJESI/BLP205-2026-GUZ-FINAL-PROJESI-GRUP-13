# BLP205-2026-GUZ-FINAL-PROJESI-GRUP-13

## Kampüs Kütüphanesi ve Öğrenci Hizmetleri Otomasyonu

BLP 205 Veri Yapıları dersi final projesi. Kitap kataloğu, duyurular, ödünç bekleme sırası, işlem geçmişi ve kampüs rotalarını yöneten C++ konsol uygulaması.

## Modüller

| Modül | İçerik | Sorumlu |
|---|---|---|
| 1 | Çift yönlü bağlı liste (kitaplar), dairesel bağlı liste (duyurular), dosya işlemleri | - |
| 2 | Stack (işlem geçmişi), Queue (ödünç bekleme sırası) | Muhammed Furkan Gençkurt |
| 3 | Bubble Sort, Insertion Sort, Quick Sort, Binary Search | - |
| 4 | Komşuluk matrisi ile graf, BFS, DFS, Dijkstra | - |
